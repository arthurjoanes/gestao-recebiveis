# Imagens da stack

Os cartões do README identificam tecnologias utilizadas no projeto. São SVGs locais, com título acessível e texto alternativo no README.

Os ícones originais de Python, FastAPI, PostgreSQL, TypeScript, React, Next.js, Docker e SQLAlchemy vêm do [Devicon no commit `7330accdbc47`](https://github.com/devicons/devicon/tree/7330accdbc47e2dc0c19789a48533c4a3c50fe58/icons), sob a [licença MIT](LICENSE.devicon). O desenho e as cores dos ícones foram preservados dentro de cartões de 72 × 72 pixels.
